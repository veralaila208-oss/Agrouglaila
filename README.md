# AgroGeo UG - Simulador Agrícola Educativo Interactivo
Autora: Ing. Laila Vera Carrasco
Institución: Universidad de Guayaquil (2026)

## Contenido de la Carpeta
1. index.html -> Interfaz principal y vistas del simulador.
2. style.css -> Estilos institucionales y animaciones.
3. script.js -> Lógica de botones, Canvas 2D, Chart.js y talleres (corregido y libre de errores).
4. README.md -> Manual rápido de instalación y ejecución.

## Cómo ejecutarlo correctamente
1. Extrae todos los archivos del ZIP dentro de una misma carpeta.
2. Haz doble clic en `index.html` para abrirlo en tu navegador.
